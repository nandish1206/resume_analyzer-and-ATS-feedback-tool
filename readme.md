# Resume Analyzer and ATS Feedback Tool

A web application designed to analyze resumes against a target job
role or job description and provide ATS feedback.

## Technology Stack

- Python
- Flask
- HTML, CSS, JavaScript
- MySQL (planned)
- SQLAlchemy (planned)
- Google Gemini API (planned)

## Setup

1. Create and activate a Python virtual environment.
2. Install dependencies using `pip install -r requirements.txt`.
3. Configure the local `.env` file.
4. Run `python run.py`.
5. Open http://127.0.0.1:5000 in your browser.
